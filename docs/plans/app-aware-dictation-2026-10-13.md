# 应用场景接入实际听写

基线：`26dce0c`（PR #11 已合并）。承接[场景成稿实验](../experiments/scene-writing-2026-10-13.md)选出的“稳定语义整理＋本地场景呈现”。本轮目标为完整接入设置、停止时目标、成稿保存和一次性交付，不再增加云端场景实验。

## 实现范围

- 设置增加“按应用调整表达”、应用偏好增改/移除和场景示例。默认启用本地呈现，旧设置缺失字段时采用同一默认；关闭后保留自定义条目。最多32项，按完整程序名匹配，大小写等价，禁止路径/通配符。现有乐观版本检查和恢复默认同时覆盖新设置。
- 常见聊天程序选择聊天；Word/WPS/OneNote选择文档；代码编辑器选择技术。浏览器和未知程序使用通用，用户可明确为整个浏览器设定偏好；本轮不推测网页任务。
- 偏好随录音开始冻结，应用身份从停止时已确认目标的进程及创建时间读取，只保留程序名。目标正文、选区内容、窗口标题和完整路径均不进入场景选择或云端请求。
- 场景在生成开始前冻结，采集迟到沿用通用处理；完成后再次核对来源、Mode、会话和目标身份。正常初次整理通过后应用本地呈现；错误回退、显式重试和历史重写不改变格式。显式 Mode / 个人规则优先。
- 预览模式也可读取停止时目标以选择呈现，但不授权输入；直接输入仍走现有原生目标复验和单次提交。浮层只显示本次选择的场景，不代表语义质量已验证。

本地呈现沿用已经冻结的 v1 范围：Auto 聊天短列表移除经过检查的前缀，保留句子、顺序、数字、条件和来源引用；文档、技术、引语/代码、显式清单以及不支持的布局保留现有成稿。自然接句与复杂改口的生成策略仍属后续质量工作。

集成复核补充：生产协调器额外保护“分点/分条/项目符号”和英文 bullets、numbered list、step-by-step 等明确排版要求；按完整英文单词匹配，不因 listening 等词误中。冻结的实验候选文件保持原样，新增规则通过实际协调器回归验证。

## 验收

1. 原生配置缺字段兼容、持久化、版本冲突、无效输入和恢复默认。
2. 实际协调器/SQLite：停止时切换应用、设置冻结、上下文迟到、目标变化、取消、错误回退、预览及单次交付。
3. 前端真实浏览器中的设置增改/移除/关闭/恢复、保存失败、键盘可达、窄窗口及浮层状态；使用合成 IPC，单独标注边界。
4. Windows 本机程序身份与可控宿主输入；不读取个人正文，不把合成文本输入等同于真人听写质量。
5. Rust 全库、TypeScript/Vite、变更审阅，通过后提交 PR。结果和未验收项写入本轮报告。
