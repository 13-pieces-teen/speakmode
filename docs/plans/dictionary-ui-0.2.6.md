# 0.2.6 词典界面精简

2026-10-09，以上一轮本机 0.2.5 为基线。桌面 0.2.6，前端 0.4.5。

用户目标：参考所给 Typeless 词典截图，减少常驻控件和说明，延续 SpeakMode 雾白、细边框、蓝色强调的界面。采用已有 React / Radix Themes；不增加依赖。设计取向为保留品牌的局部精简，DESIGN_VARIANCE 3 / MOTION_INTENSITY 2 / VISUAL_DENSITY 4。

## 改动

- 页面保留一个标题、新词、搜索、词条数与轻卡片网格；宽屏三列、中屏两列、窄屏一列。
- 点击词卡编辑，省略号菜单提供编辑／删除；取消每行常驻双操作按钮。
- 新词／编辑改为居中小弹窗。批量按行粘贴放在弹窗次级入口，没有新增 CSV 导入。
- 正常容量藏在折叠说明；接近上限时提示，草稿可能超限时展开详情。保守估值不禁用保存，后端继续执行 Unicode 去重与整批容量限制。
- 删除使用明确确认框；保留草稿退出保护、提交互斥、版本冲突重读与下次录音生效。
- 修复保存并切换编辑模式时排队回调使用旧词库版本的问题；冲突时展示当前已保存词条；并发删除导致对话框自动关闭时恢复焦点。
- 未增加自动学习来源分类，因为当前词条没有自动／手动来源字段。

## 验证与边界

独立合成 bridge 浏览器检查增改删、搜索、四尺寸／长词、弹窗焦点与 Escape、dirty guard、保存后切换批量、冲突、加载／读取失败／空态。原有容量组件与浏览器断言保留。真实个人词库、云服务、麦克风和跨应用输入不参与 UI 测试。

Windows 包复用原 MSVC 缓存；保留 0.2.5 语义改动，不修改原生词库存储和语音链路。完成结果见[验证记录](../experiments/dictionary-ui-0.2.6-2026-10-09.md)。
