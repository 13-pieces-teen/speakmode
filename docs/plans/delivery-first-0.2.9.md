# 0.2.9：整理可降级，输入不中断

日期：2026-10-10。桌面 0.2.9 / 前端 0.4.8，基线为本地 0.2.8 工作树。保留之前词典、浮层 Mode 和轻语增强的改动。

## 产品结果

一次正常听写结束后，优先在结束时捕获的输入位置得到文字。整理超时、服务失败、输出格式错误或有限事实检查拒绝时，自动选择已经完整收齐并保存的识别稿，继续原有的一次性输入流程。错误候选不输入，不先输入原稿再用迟到结果覆盖。

自动输入确实无法完成时，在浮层直接复制；用户无需去主面板重新整理。已发送但无法确认宿主接收的状态保持如实描述，不自动再次发送。

| 0.2.8 行为 | 0.2.9 改动 | 主要验证 |
| --- | --- | --- |
| 整理拒绝后整个会话失败 | 初次听写选择完整识别稿，保存后继续输入 | 真实 SQLite + 注入失败、取消、迟到、重复结束与保存失败 |
| 错误恢复提示去主面板 | 浮层复制当前成稿或未完整识别的现有文字 | React 交互 + 录音窗口 IPC 权限、身份与竞态测试 |
| 数量词和程度词引起误拦 | 有限规则区分不定冠词、程度词及明确计数；修复中文时刻 | 64 个正反例，保留原 32 例回执 |
| 所有整理沿用 20 秒上限 | 初次短口述最多等 5 秒，长口述/重试维持 20 秒 | Unicode 800/801 字符边界及实际超时回退测试 |
| 回退结果容易被当作 Mode 整理成功 | 持久化回退原因，历史显示“识别稿”，诊断单独计事件 | 旧数据兼容、重开数据库、撤销与显示测试 |

## 实现边界

1. 仅 `NormalInitial`、完整且合法的 source、checkpoint 已提交、当前 session/generation、未撤销原输入资格时自动回退。ASR 未收齐不能冒充完整成稿；取消和历史重试不自动粘贴。
2. 保底稿保存原 source 全文和全部来源引用。数据库提交成功后，复用目标校验、提交账本和 once-only permit，不绕过剪贴板/原生派发的并发保护。
3. `rewriteFallback` 为可选字段，不需要 SQLite 表结构迁移，旧记录仍可读。回退不计 `RewriteValidated`，只计 `RewriteFallbackSelected`。人工编辑清除回退标记，撤销可恢复原标记。
4. 浮层只可复制当前会话及 generation；不能凭历史 ID、任意 output ID 或 `sourceOnly` 读取历史。复制等原生派发结束；复制失败可重试复制，不重试自动输入。
5. 短口述定义为来源正文不超过 800 个 Unicode 字符。5 秒是基于短合成文本延迟并留余量的工程预算，不是结束录音到插入的 SLA；ASR、来源保存、目标检查和输入另有耗时。长口述、弱网和冷连接没有由此得到性能保证。
6. 用户主动选择“预览后输入”仍遵循原偏好。主面板的来源对照、手动整理、恢复和撤销继续保留。

## 微整理选型

所有 Mode 的目标仍是去无意义语气词、重复开头和明确改口，同时保留事实、条件、否定、不确定性及新增细节。Mode 只决定呈现。新版清理提示和更强模型必须用相同来源与 Mode 比较；模型产出、校验接受、实际可采用成稿分别记账。

本版同时维护冻结合成语料、受限云端实验入口、隐藏模型身份的独立 Agent 复核和当前 parser 离线重放。任何未达到保真要求的提示不因文字更短就替换生产默认。最终选择、数字和发行验证见[本版实验记录](../experiments/delivery-first-0.2.9-2026-10-10.md)。

## 后续验收

真实人声、具体宿主中的右 Alt 全流程、用户轻声与正常声的识别率、安装升级卸载继续分开验收。已有 Windows 自有输入框测试不等于所有软件的输入兼容性；合成文本整理不等于 ASR 准确率或 HCI 用户实验。
