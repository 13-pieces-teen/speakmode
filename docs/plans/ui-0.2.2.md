# SpeakMode 0.2.2：常用页面体验精修

2026-10-09。基线为已合并的0.2.1（`c30acdd`），本轮集中前端体验，保留Windows云端口述、当前Mode、词典和来源恢复契约。

## 现状审查与保留项

延续现有雾白画布、白色卡片、冷灰细边、蓝色强调、SpeakMode Sans／Windows中文字体及Radix组件；页面导航名称与信息结构保持。各功能块仍使用一致卡片，今日次数、字数和时长继续在首页顶部。保留录音浮层、逐句来源对照、局部恢复、撤销及所有原生资源准入。

源码确认：首页正文不受限；历史列表依赖整页滚动；搜索等待中可能提前显示无结果；设置反馈在长页末尾；720px窗口中五项导航使用四列。设置默认Mode在个人模式增多时不断增高，词典关闭内联操作后缺少明确键盘焦点落点。采用保留式精修，视觉差异低、动效克制、信息密度适中，不引入新的设计系统。

## 本版增量

| 场景 | 0.2.1体验 | 0.2.2目标 | 验收 |
| --- | --- | --- | --- |
| 首页长口述 | 正文将复制操作和历史推到数屏之后 | 默认显示有限预览，可展开／收起；复制完整成稿；顶部用量位置保持 | 长短文字、展开收起、完整复制请求、各窗口尺寸 |
| 历史查找 | 搜索中缺少反馈，空结果判断过早 | 明确加载状态；请求完成后才显示无结果，旧错误不污染新搜索 | 延迟与乱序合成请求 |
| 历史阅读 | 长详情滚动后难找记录和搜索框 | 宽屏列表独立滚动，标题／搜索可见；窄屏保留列表与详情切换 | 16条记录、长正文、720／1024／1440布局 |
| 详情操作 | 展开的操作区可能在视口之外 | 换整理、纠词、删除进入操作区；取消回到触发处 | 真正点击与键盘焦点检查 |
| 设置反馈 | 保存成败统一放在页尾 | 紧邻刚操作的行反馈保存中、成功或错误；保留防重入 | 延迟成功／失败，不遮挡控件 |
| 设置Mode | 个人Mode逐项铺开占据长页 | 紧凑选择，全部模式可达，保留说明和示例 | 10个个人Mode与长名称、键盘选择 |
| 小窗口与键盘 | 导航换成两行，词典焦点可能丢失 | 五项导航整齐排列；编辑／删除／清查询后焦点有去处 | 720px最小原生宽度与额外430px布局回归 |

本轮不改变语音模型、提示词、采音、自动输入或存储。浏览器验收使用生产React和合成Tauri数据，不读取个人历史、Key或录音；与真人、真实宿主和安装升级验收分开。按改动范围运行前端构建、相关行为回归与正式Windows打包，不把纯视觉调整解释为听写质量提升。
