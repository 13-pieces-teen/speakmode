# 0.2.10：默认自动听写的自然整理

日期：2026-10-10。基线为本地 0.2.9 工作树。实验已完成：**生产只启用已验证的限定校验修复，新协议 / 3.8 Flash 不升为默认**；最终库测试与构建收据见[验证报告](../experiments/automatic-dictation-0.2.10-2026-10-10.md)。

交付更新（2026-10-11）：0.2.10 / 0.4.9 EXE 与 NSIS 已生成，597 项 Rust 库测试通过；174 项构建输入、版本及复制摘要核对通过。实际人声、宿主输入及安装升级未在本轮验收。

## 本轮增量

用户无需为去语气词、处理明确改口及正常断句选择 Mode。以最终输入的文字评价默认自动体验，继续保留 0.2.9 的一次性交付、完整识别稿回退、来源保存、恢复与撤销。

| 0.2.9 | 本轮候选 | 验收方式 |
| --- | --- | --- |
| 模型同时编辑正文、分配来源范围 | Auto 无个人规则采用显式整段输出，程序绑定全部来源 | 严格协议测试、来源不变性、同输入真实云端对照 |
| 词典只进入识别，整理层没有专名提示 | 仅提供当前识别稿已命中的标准拼写，最多 32 条/1024 字符 | 整词匹配、容量、引用/代码/路径边界及命中样例 |
| 来源范围错误可能让有效清理被丢弃 | 新协议无需生成来源索引；原有限语义检查继续执行 | 分开报告候选、校验接受和预计交付，不补旧协议的缺失来源 |
| 大小写和标点在 CER 中不可见 | 额外评审专名书写、口语清理、断句、口吻和意思保留 | 独立隐藏实验组的 Agent 评审，明确不等于真人验收 |

## 协议及范围

- 新协议只有 `resolvedMode` 和 `text`；Auto 只能解析为 light/structure。源文、引文及词典均为数据，不执行其中指令。
- 一份成稿绑定整段原音识别来源；可以做整段对照及已有局部手工恢复，不能宣称精确逐句来源对应。
- 第一轮限定 Auto 且个人规则为空。明确选择的轻整理、结构和带个人规则的 Mode 保留原契约；不擅自修改已有用户偏好。
- 词典只帮助普通语境中 `typeless → Typeless` 这类字母完全相同的书写。不会将 `swing mode` 或 `Speed Mode` 猜改成 SpeakMode；识别错误仍需 ASR 热词/音频实验处理。
- 原始识别稿不改写；整理失败的 source fallback 仍逐字采用原稿。取消、重复结束、保存失败、迟到候选和无输入目标仍沿用原保护。

## 对照与选择

开发第一轮 24 次请求已完成，发现词法误拦及候选过度书面改写，v1 不启用。修正为 v2 后，针对用户补充的“更好且快的模型”，追加三组各24次有限开发对照（总开发上限96次）：候选分别使用 qwen-flash、qwen-plus、qwen3.8-flash，基线始终保留原配置 qwen-flash；同一份 v2 提示、固定语料及校验，不按结果重试挑选。每组8条已有开发脚本与4条专项样例，AB/BA交替；新模型只在实验内存配置生效，不写用户配置/Key，不读历史正文、不录麦克风。候选同时改变提示、协议和源文命中词典，是组合对比，不能将收益全部归给其中某一项。新模型的效果及速度以实际请求为准，接口支持不代表账号已开通。

候选冻结后再使用 4 条预留验证脚本，每条 2 次、每次 2 个实验组，最多 16 次。无自动重试；鉴权/额度或连续服务失败停止，不用重跑挑最好结果。脚本转固定文本输入，所以这是文本整理实验，不是 ASR 准确率、Typeless 实测或自然人声实验。

开发追加决策：前三模型的 v2 对照已完成。3.8 Flash 的生成正文在12条中未被独立 Agent 标记关键错误，云端请求中位约1007ms；Plus约1386ms，仍有判断口吻/引文保留要求遗漏。v2仍有正确改口及中文量词误拦。修复限定词法、明确改口撤回与整数时刻提取后，v3增加程序抽取的保留线索，追加一次24请求开发验证，只测选出的3.8 Flash，不重试前三模型。开发总上限120请求，随后16次预留验证；两阶段总上限136。原始失败证据保留，新增结果不能覆写已有收据。

所有请求留在分母；同时记录模型输出、parser 接受与正常初次会话策略下的预计交付。预计交付不是实际宿主粘贴证明。关键意义错误单列，不靠可读性抵消。未执行的数据保持 NOT_RUN。

默认启用候选之前，需看到整体整理收益，且独立检查没有发现新放行的关键错误；若未达到条件，只交付已验证的窄修复，不静默启用失败方案。

最终结果：开发 v3 接受且完整可用 5/12→9/12，预留却为 3/8→3/8；预留生成正文完整可用从 7/8 降至 3/8。候选五次扣分均因原 Agent 将保留“啊”判作清理不足，存在情绪与强调的主观边界，不能直接推导模型更差。两组预留均未评出关键错误。没有根据这一小批预留继续调提示或重跑，保留全部 136 次真实请求。生产保持原模型配置与 `mode-contract-v1`；新版修复词法“区别/差别”、有限停顿的数值作用域、严格相邻数字改口撤回及明确整点保护。整段协议与源文命中词典仅由显式实验入口使用，录音的词典快照接口准备不等于已启用质量提升。
