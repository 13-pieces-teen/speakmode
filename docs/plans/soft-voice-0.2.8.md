# 0.2.8：轻语增强

2026-10-10。基于本地 0.2.7 工作树增量实现，桌面 0.2.8／前端 0.4.7。保留当前工作树此前版本的功能；本轮没有更换默认 ASR、云端 VAD、整理模型或提示词。

## 产品行为

- 设置 → 音频 → **轻语增强**。适用于保留正常音调的轻声输入，建议安静环境；不是气声耳语支持承诺。
- 默认关闭，旧配置缺少字段时关闭；设置保存到现有偏好数据库，重启保留。恢复默认会关闭。
- 对所有输出 Mode 生效。每次开始录音时冻结偏好，录音中保存只影响下一次。
- 右 Alt、长停顿、字幕、停止后的整理与输入流程沿用现状。波形仍来自真实采集电平，没有通过放大动画伪装识别提升。

## 实现约束

`platform/audio_conditioner.rs` 在重采样后的 16 kHz 浮点数据上原位运行，处于采音工作线程，设备回调无新增处理。每 10 ms 观察一次，前 10 ms 保留输入，之后平滑调增益；无 lookahead、无新增音频缓冲、无噪声门、无样本裁剪。网络仍为 100 ms 帧，原有停止 drain 和 padding 语义保留。

版本 `soft-voice-v1`：增益上限 12 dB，目标 RMS -25 dBFS，启动能量条件 -60 dBFS，估计噪声余量 9 dB、估计噪声输出上限 -45 dBFS，峰值上限 -1 dBFS。调增益时间常数约 40 ms，减增益及峰值恢复约 80 ms，短暂保持 120 ms。这些是待真人实验验证的首版候选参数，不是普遍适用的声学阈值。

重试缓存保存已经增强的 PCM；重放不重新调用处理器，不受后来开关变化影响。固定 +6 dB 仅用于实验入口；产品只有关闭／开启两态。

`conditioning.realSamples` 为处理过的非 padding 16 kHz 样本数，可能包含已有重采样前导延迟；入队失败时可包含处理完但未送出的一帧。设备采样数、处理数、队列数、云端写入数分别保留，不能混为一谈。诊断是会话内存聚合，导出继续使用类型白名单。

## 已知限制与质量验收

这层改变数字电平，不能凭空提高输入信噪比或恢复驱动已删去的细节。模型若自身已经做归一化，识别改善可能很小。音调稳定的机器噪声也可能满足启用增益的条件；极弱或低信噪比语音可能不增强。因此先保持默认关闭，不能宣传“已提升准确率”。

原方案中的分通道测量、真实 SNR、校准、降噪模型、系统 RAW 采音、VAD/识别模型比较均未在本轮实现。按 [可行性方案](soft-voice-feasibility-2026-10-10.md) 收集真人轻声与正常音量、键盘/风扇/静音负例，冻结参数后同音频配对比较 ASR 原稿，再检查同一 Mode 的成稿。没有真人测试素材时不以数字衰减或正弦波代替准确率验收。

实验工具 `voice_lab` 每条 asrRuns 可传 `conditioningProfile: bypass|fixedGain6Db|softVoice`；缺省旁路。同一原始 PCM16 只处理一次，18 请求／600 秒单批限制保留。PCM16 试验无法恢复录制时已经量化丢失的细节。离线质量评分的素材与参考同时标注 `expectation: no_speech`，空参考/事实/词条/模式条件，失败与缺失单独报告。

验证与发行结果见 [实际验证记录](../experiments/soft-voice-0.2.8-2026-10-10.md)。
