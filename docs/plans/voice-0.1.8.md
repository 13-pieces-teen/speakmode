# SpeakMode 0.1.8：语音质量基础

维护日期：2026-10-08。比较基线：桌面 0.1.7／前端 0.3.2，提交 `3fd71f338628f82ae8b13bc59bcf2c9f996e3d13`。本轮实现[质量路线](voice-quality-roadmap-2026-10-08.md)第一阶段的代码与本机评测流程，桌面升至 0.1.8／前端 0.3.3。默认仍为 `qwen3-asr-flash-realtime` → `qwen-flash`。

## 增量与验收

| 改进 | 0.1.7 行为 | 0.1.8 行为 | 已能验证的收益 |
| --- | --- | --- | --- |
| O04 PCM 持续性 | 只检查启动后是否首次收到音频 | 成功提交非空 PCM 后更新单调时钟；连续 5 秒无回调判中断；首次等待仍 10 秒 | 不再无限显示录音却没有采音；数字静音连续回调 60 秒仍正常，不因翻资料结束 |
| 故障指引 | 部分采音错误最终呈现一般 ASR／不完整错误 | 明确区分启动无音频、持续停滞、设备错误、队列满与格式错误 | 已有字幕保留，失败不 Ready／计数／自动输入，取消与主动结束优先 |
| 模型能力注册表 | 模型名可自由输入，接口版本容易误配 | 原生验证模型、协议、适配器和产品已接入语言；主窗口提供同一清单，设置用选择器 | 保存前拒绝未接入协议；已有未知配置不自动改写，用户选择已接入模型后可保存 |
| 有限 O06 事实保护 | 中文时间、否定、条件等限定检查 | 额外检查有限数值、单位、版本、局部对象、数值否定角色、单目标改口及英文限定范围 | 登记的金额交换、单位改变、否定移位挑战被拒绝；正常数词和单位转换允许 |
| 可重复离线质量评测 | 主要依赖固定 TTS 及临时复核 | manifest／音频／参考／配置冻结；primary 与 diagnostic 分离；双人评分及统计 | 对同一录音比较候选，失败和缺失保留分母；未录音不生成质量成绩 |

5 秒是初始工程阈值，不是已验证的所有设备保证；系统高负载与真实设备断开需另测。RMS=0 与没有 PCM 是两回事。持续性检测关注音频供应，与网络连接心跳无关；不会自动结束正常静音。

## 模型与配置

`cloud/models.rs` 是兼容信息的唯一产品来源。已接入旧实时协议的默认模型与 `2025-10-27`、`2026-02-10` 快照可选择；文本候选使用既有 Chat Completions／JSON object 路径。候选列表不代表质量排名、账号授权或真实连接验证，也没有把 strict JSON Schema 切入产品请求。

Qwen Audio 3.x Task Streaming、Fun-ASR 和文件识别作为禁用项标记未接入，不能将新名字套到旧 `session.update` 协议。保存配置和构造生产请求前执行原生校验；试用／候选／失败重试也在读取凭据前先验证配置。配置仍用版本 CAS；已录音会话保留自己的配置快照。

已有未知模型、接口错配或空模型名会提示重新选择；不会迁移或删除用户 Key。选择有效组合后保存配置，再使用原有录音链路验证账号。Key 从不回填前端。默认模型、采音格式、VAD、帧长、提示词主契约、温度和一次性输入策略保持既有实现。

## 事实检查边界

有限检查是拒绝可识别风险的规则，不是语义等价证明或自动纠错模型。保留来源引用和全覆盖检查；风险失败进入已有来源找回／重新整理入口，不尝试把错误金额自动猜成正确值。

支持登记的中文数词／十进制、百分比、部分金额和时间单位转换；版本保留分量和尾零，GB／GiB、元／美元等不混用。局部纠正只接受明确单目标日期或数量“把／将 X 改成／改为／改到 Y”，其余条件保留。英文检查为列出的 ASCII 词和常见缩写词界。

复杂关系、未知单位、所有实体、所有新增事实及泛化语义判断仍未覆盖。未知同义表达和跨句合并多个英文否定可能误拒绝，未匹配的语义变化可能漏拦。必须在真人同音频评测中同时统计错误接受与合法改写误拒绝，不以规则测试推出准确率提升。

## 交付和后续实验

代码回归与构建收据见[实际报告](../experiments/voice-0.1.8-2026-10-08.md)。[离线工具说明](../experiments/voice-quality-lab.md)包含 24 条真人任务生成、冻结、结果登记、双人评分和统计命令；目前任务未录音，成绩为 `NOT_RUN`。

用户安装新版后，先验证右 Alt 开始／结束、说话时波形／字幕、真实 30–60 秒停顿后继续、正确光标输入。两种 Mode 都应保留“预算3500元，不是5000元”“如果没确认，先不要发邀请”等有效事实，明确改口与格式转换不应被误拒绝。比较模型需要固定同一音频与配置，首次失败保留。

新 ASR 适配器、默认模型切换、自动二次识别、成功录音缓存、O05 独立恢复槽、O07 候选对照及 O09 词典容量 UI 不在本轮实现。真实 Windows 宿主输入、安装升级／卸载、人声质量与高负载设备验收仍分别记录。
