# 0.2.12：Typeless 词汇导入与安静完成

日期：2026-10-11。用户要求一键迁移 Typeless 常用词，并去掉口述结束后主面板中的“输入已派发／查看成稿”大卡片。

## 功能边界

- 词典页增加“导入 Typeless”，由用户点击后读取该来源的词汇，追加到 SpeakMode；自动跳过大小写、全半角等重复词，保留已有拼写。
- 不修改 Typeless，不从口述历史推断词汇，不上传迁移内容；不读取或迁移它的账号凭据。来源适配必须依据实际存储结构，不猜测数据库字段。
- 实际来源为已确认的 Windows Typeless 2.8.1 本机 Chromium blockfile 缓存。只接受仍在 active index 内、未筛选且条数完整的词典接口响应；先选择最新响应，再校验完整性，不从旧响应拼词。界面说明缓存可能落后于云端，刚修改词典时需先在 Typeless 打开“所有”页更新。
- 使用现有词库版本检查和原子事务。来源不存在、格式不支持、词条无效或容量不足时，明确提示且不部分保存。当前录音继续使用开始时冻结的词库，导入供下次录音使用。
- 页面显示简短导入结果；处理中避免重复提交和离页丢失结果。恢复已有词典列表、搜索、新词和批量输入行为。
- 正常口述交付后移除主面板的恢复卡片。实际未输入、部分输入、失败或内容未保存仍保留必要操作；不据此改变原生交付凭证或将“派发”表述为“已确认粘贴”。
- 不自动打开主面板、不自动再次输入、不清除用户历史和恢复内容。

## 验证

来源读取使用隔离数据覆盖解析、只读、重复、无效/超限、未知格式等分支；数据库验证原子写入、并发冲突和重复导入。生产 React 合成桥检查按钮、状态、异常、键盘和窄窗口；完整 Windows 回归及 EXE/NSIS 构建后登记最终结果。真实来源读取与实际导入、合成浏览器与 Windows 使用分别报告。
