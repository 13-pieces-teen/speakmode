# 0.2.13：自然微整理与回退诊断

日期：2026-10-11。基线为 0.2.12 / 0.4.11。用户要求删除无意义语气词、合并重复和残句、自然分段，同时保留个人口吻、备选方案和不确定性。

## 已确认问题

只读检查实际安装版资料的最新来源，与用户本轮提供的 388 字口述忽略标点与空白完全匹配，保存的 `rewriteFallback=meaningRisk`。这次是整理结果被有限语义检查拒绝后交付完整识别稿，不可归因为模型完全未做清理。现有诊断的 ready 状态会覆盖错误字段，回退时缺少整理耗时；本版补独立且无正文的整理诊断。

当前安装版配置为北京地域、`qwen3.8-flash`。旧项目 runtime 资料仅到 10 月 8 日，不作为这次用户使用的配置来源。实验和验证不得修改用户配置、词库、历史或凭据。

## 预注册实验

- 12 条公开匿名合成开发文本，两臂各一次，共 24 次真实云端请求。包含短口述、三条长口述、引用/代码、应答、数字、否定/条件、改口、连续设想与真实步骤。
- 8 条由独立 Agent 编写的预留文本，其中三条 250–550 字；候选冻结后执行两臂各一次，共 16 次。预留集具体内容不用于提示调试。
- 用户提供的原文单独放在仓库外私有案例文件，两臂各一次，共 2 次。原文与其完整输出不纳入公开仓库。
- 本轮最多 **42 次请求**，无自动重试、额外模型或挑选最佳生成；鉴权或连续服务故障停止并保留所有失败。两臂均显式使用 `qwen3.8-flash`，不写回配置。
- 基线使用实际生产 `mode-contract-v1`；候选 `natural-cleanup-v1` 默认自然段，明确清单/步骤才分点，用整段 `text` 协议，程序绑定全部来源并复用有限语义校验。协议改动和提示共同构成候选，收益不可全部归因于其中一项。
- 文本分片是固定合成切分，非实际 ASR 分片；记录生成正文、耗时、解析/语义接受与按现有预算模拟的最终交付。实验不是 ASR 准确率、Typeless 同音频测试、真人修改成本或实际 Windows 粘贴验证。

## 评审与选择

保留全量请求为分母。生成结果和回退结果去重、隐藏实验组后独立评审：先检查全部有效信息、数量/否定/条件/引用、观点与备选关系，再评卡顿清理和段落自然度。承载答应/强调的语气词与引文不按无意义噪声扣分，不要求与单一参考句完全一致。关键语义错误不可被流畅度平均分抵消。

开发阶段可根据最小离线对照修复明确的有限检查误拒，必须覆盖相反错误输出，不降低整体数字、否定或来源保护。旧实验原始响应与旧拒绝结果保留；离线复验单独标注，不能冒充重新云请求。预留阶段开始后冻结提示及守卫，不按预留成绩修改再重跑。

候选仅在开发及独立预留均显示可用交付改善、未新增关键语义错误且耗时可接受时进入默认 Auto 无个人规则路径；轻整理、结构及个人规则合同保持原实现。如果达不到条件，交付已通过回归的窄修复及诊断，明确候选保留实验状态。

## 交付约束

继续优先一次性交付，完整识别稿保底、取消和迟到结果处理不变；不自动第二次粘贴，不弹出主面板要求用户整理。只有实验提供证据才调整等待预算，不因猜测延长。保存原来源与恢复能力，不用机械全局删词处理兜底原稿。

完成后记录增量、原始失败、最终统计和证据范围，运行相关单测、完整 Rust 回归、前端构建以及 Windows EXE/NSIS 打包。安装器和应用由用户自行启动验收。

## 开发修订记录（预留集仍封存）

v1 已执行开发 24 次和私有样例 2 次。开发独立 Agent 评审显示生成正文完整可用 8/12→11/12，按旧守卫模拟最终可用 7/12→9/12；但用户样例两臂都缺少自然分段且遗漏后一个“可能”的作用，均不满足目标。不能根据开发平均分直接晋级。

在未读/执行预留集之前，作最后一次提示开发修订 v2：逐项保留不确定性，长口述遇真实话题转折要实际空行分段。追加新开发 24 次及私有样例 2 次，随后冻结进行既定预留 16 次，本轮总上限调整为 **68 次**。不修改语料、评分标准或旧失败记录，不再进行第三轮提示调试；若仍不达标，仅交付有明确证据的窄修复。v1 原始源文件和所有请求/评审保留，v2 与新守卫同时作用的结果须标注为组合改进。

## 预留完成与发布选择

68 次请求全部完成，未额外调用。预留 8 条两臂均完整可用 8/8，未确认候选的最终交付增益；用户提供的样例 v1/v2 两臂仍均被不确定性作用域检查拒绝。**不晋级 natural-cleanup-v2，不更换默认模型、提示或等待预算**；发布范围为有限误拒修复和内容无关诊断。

预留完成后，独立代码审阅发现新数量豁免的两个缺陷：把不同主体的一与二对比当引入语，以及漏读跨 ASR 片段的“只提供”限定。本轮允许仅收紧这两个实现缺陷，新增反例，不按预留文本新增放行类型或调整提示。保留云端运行时源码哈希/快照、原始响应和评分；修后仅离线重判相同响应并记录新哈希，不冒充新云测或独立确认。原盲评只按来源、输出及标准全部相同时转用。
