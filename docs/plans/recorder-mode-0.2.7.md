# 0.2.7：录音浮层的轻量 Mode 菜单

日期：2026-10-09。基线：本机 0.2.6；桌面版本 0.2.7，前端 0.4.6。

## 问题与增量

| 原行为 | 本版调整 | 验收方式 |
| --- | --- | --- |
| 窗口透明规则同时命中 Radix Popover，页面文字透过菜单显示 | 透明仅作用于文档与根 Theme，菜单保持实色白底 | 检查菜单与祖先透明度、动态帧及合成文字背景截图 |
| 280px 宽、61px 高选项、大图标底座、常驻说明和重复页脚 | 216px 宽、36px 高单行选项，保留图标、名称、勾选；说明移入 title | 核对尺寸、长名称省略和选择命令 |
| 整张菜单滚动，字幕和错误展开后可能超过 420px 窗口上限 | 固定标题，选项内部滚动；用剩余窗口高度限制菜单 | 个人 Mode 长列表、错误、字幕和录音时限提示的组合检查 |
| Radix 默认出入场不符合高频工具切换 | 鼠标展开 150ms 小位移／缩放；实色背景全程保持；收起立即响应 | 动画帧、快速重复开关、关闭 resize 请求 |

## 交互约定

- 标题“本次 Mode”明确选择范围；不改录音默认 Mode。
- 长个人名称单行省略，键盘方向键、Home、End 可定位选项；列表独立滚动。
- 等窗口扩展和 Radix 定位均完成后才显示菜单，避免原 86px 小窗口的首帧裁切。等待时保留可测量布局，显示后再聚焦选中项。
- 使用 CSS 状态驱动的 transform 过渡，不透明度保持 1；`@starting-style` 补充首次绘制状态，不引入依赖。
- 键盘打开、托盘打开和系统减少动态效果均即时展示。关闭不等待动画，及时交还宿主焦点。
- 打开菜单时暂时将展开字幕压为一行并隐藏阅读提示，关闭后恢复阅读状态；字幕文本、冻结位置与采集均保留。
- 保留托盘输入位置提示、会话身份／generation／revision 校验、异步操作隔离、失焦只收起菜单。
- 原生透明窗口、非激活展示、多显示器位置、目标校验、采音和 Mode 整理规则沿用现有实现。
