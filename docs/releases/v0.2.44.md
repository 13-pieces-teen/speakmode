## SpeakMode 0.2.44

本次包含自 0.2.38 公开 Release 以来的语音、恢复及快捷键改进。

- 录音到时长上限时，正常收尾并保留预算内完整音频，成稿交由预览；手动停止与到限同时发生时也不会自动输入裁剪后的文字。修正重采样尾部和时长计算，减少末尾语音丢失。
- 所有整理模式统一进行完整内容复核和词典规范化，最多修复一次；明确的紧邻命名改口可正确撤回旧名称。纠正及最终复核中的凭据、限流和配置等错误保留分类，避免无效自动重试。
- 整理失败时保留识别稿；未完成项目进入独立恢复列表，不再阻塞下一次录音。可选择录音时或当前服务配置重试，重试结果由用户手动确认和复制。
- 识别收尾或整理过程中可以复制已有文字，复制成功后撤销本次自动输入；整理继续，并保留原邮件、聊天等场景及已授权上下文。优化处理中阶段提示、取消和复制操作。
- 所有有效录音快捷键统一为：第一次开始；500ms 内再次触发取消；超过 500ms 再次触发停止并整理。修正取消、慢停止后的排队按键残留和再次录音行为。
- 修正临时文字清理、来源保存顺序、过期请求占用忙状态及采音终止通知遗漏。

### 使用边界

- 单次自动整理来源上限为 `sourceText` 经 JSON 编码后的 6144 UTF-8 字节，纯中文通常约两千字；超限保留完整识别稿供复制分段处理，不自动分块。
- 换用单次录音时长更短的识别服务重试，仍可能在回放后才提示超限；本次未改动这项行为。
- 升级会退出应用。请先保存仍在录音或恢复列表中的未完成内容；持久历史、设置、模式和 API Key 按原地升级流程保留。

### 验证范围

发布前本地 Windows MSVC desktop 库回归 1155 通过、0 失败、4 忽略；非测试桌面检查、TypeScript/Vite 生产构建及 8 组前端 helper 检查通过，其中录音交付/恢复 helper 34/34。GitHub 标签构建另外运行桌面库测试、前端构建和 NSIS 打包。

回归覆盖合成音频、脚本化模型响应、loopback HTTP 和 SQLite；真实麦克风、真实云模型质量、目标应用输入及安装后的完整语音使用仍需实际验收。
