# MVP 定位与交互

目标是让用户顺畅口述、得到适当整理，并在 AI 改动影响原意时能够查到来源和修复。产品优先覆盖 Windows 日常输入场景。

## 连续任务

1. 在文本输入位置按右 Alt，开始录音。
2. 看真实音量反馈和滚动识别字幕；可以停顿、查资料、移动输入位置。
3. 选择 Auto、轻整理、结构或个人 Mode，再次按右 Alt 结束。
4. 等待识别尾段确认与文字整理；结束时捕获的输入目标在派发前再次校验。
5. 自动输入尝试一次。无法识别可写位置、目标变化或派发失败时，明确提示并保留成稿。
6. 在历史详情中对照识别稿，局部恢复或撤销，再复制修订结果。
7. 专名听错时可选中这一处纠正，并主动选择“记住这个写法”；下一次识别使用更新后的个人词典。不会偷偷改动其他应用里已输入的文字。

录音中的字幕是识别稿，结束后的成稿才是 Mode 整理输出。正常流程不额外增加确认步骤；产品不会在用户结束后换到其他输入框时把迟到结果投进去，也不会自动重试粘贴。

## Mode 与原意

轻整理清理无意义口头语、意外重复和明确的自我纠正，保留信息顺序和语气。结构在同样清理后，按内容依据组织标签、要点或步骤。Auto 选择这两种任务之一；个人 Mode 加入用户的格式规则。

0.2.19 在已验证的百炼北京 / qwen3.8-flash 下，共用基础微整理，再决定自然段或列表。自动路径最多一次局部修复，仍在原等待期限内；失败使用完整识别稿，取消或来源失效不能输入。明确的局部纯句头删除可逐字核对后本地验收，其他修复需要新的全文核对。Mode 试用每种布局生成一次可供用户检查的草稿，不授权自动交付。

条件、否定、不确定性、数字及时间限定都应保留。来源 ID 覆盖检查能够发现遗漏映射，不能证明语义一定正确；因此识别稿、逐块来源对照、局部恢复和撤销仍是核心功能。

在历史中主动生成候选时，默认展示划线和蓝色改动，可逐处保留原文或采用改动，也可直接编辑全文。有限的数字、限定和引语核对提示不会锁死有效草稿；保存需要用户明确选择，并继续核对候选身份、来源和当前版本。取消只丢弃候选；保存后可撤销，不会重新输入到其他应用。过长或改动过多的文本明确按整段对照，正文不会被截断。

## MVP 边界

目前云端链路只支持百炼；不引入订阅、账号、团队协作或复杂生产力仪表盘。本地保存与“不保留历史”的临时结果策略都由原生后端管理，前端不成为数据库或密钥的权威来源。

自定义 Mode、服务地域及麦克风在设置/Mode 面板配置。悬浮栏保持录音、Mode、取消和结束的核心操作；错误恢复按实际阶段呈现，不把云失败、保存失败和输入失败混成成功。

个人词典用于记录项目名、人名、缩写等常用专有词，支持手动维护、多行批量添加和显式纠词记忆。修改从下一次录音生效；词库会随识别请求发送给配置的云端服务。它是识别提示，不保证每次命中；最终文字仍可通过识别稿对照与恢复修正。不会自动学习历史或宿主中的文字；撤销一次文本纠正不会删除明确记入词典的词。

个人Mode提供英文保留、简洁自然、简体中文、少些客套的快捷偏好。它们加入可编辑的整理要求，随该Mode保存；不引入新的Mode档位或后台画像。

0.2.1 在本次运行内额外保留一条可重试的失败录音，期限沿用原30分钟。开始新录音后，可在主面板打开旧条目，再明确重试识别；不会自动请求云服务或重发输入。放弃旧条目需要确认，槽满或当前内容尚未保存时给出处理提示。词典页面同步展示实际容量与草稿容量上限，后端校验仍是最终依据。
