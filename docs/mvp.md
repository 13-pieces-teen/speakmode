# MVP 定位与交互

目标是让用户顺畅口述、得到适当整理，并在 AI 改动影响原意时能够查到来源和修复。产品优先覆盖 Windows 日常输入场景。

## 连续任务

1. 在文本输入位置按右 Alt，开始录音。
2. 看真实音量反馈和滚动识别字幕；可以停顿、查资料、移动输入位置。
3. 选择 Auto、轻整理、结构或个人 Mode，再次按右 Alt 结束。
4. 等待识别尾段确认与文字整理；结束时捕获的输入目标在派发前再次校验。
5. 自动输入尝试一次。无法识别可写位置、目标变化或派发失败时，明确提示并保留成稿。
6. 在历史详情中对照识别稿，局部恢复或撤销，再复制修订结果。

录音中的字幕是识别稿，结束后的成稿才是 Mode 整理输出。正常流程不额外增加确认步骤；产品不会在用户结束后换到其他输入框时把迟到结果投进去，也不会自动重试粘贴。

## Mode 与原意

轻整理清理无意义口头语、意外重复和明确的自我纠正，保留信息顺序和语气。结构在同样清理后，按内容依据组织标签、要点或步骤。Auto 选择这两种任务之一；个人 Mode 加入用户的格式规则。

条件、否定、不确定性、数字及时间限定都应保留。来源 ID 覆盖检查能够发现遗漏映射，不能证明语义一定正确；因此识别稿、逐块来源对照、局部恢复和撤销仍是核心功能。

## MVP 边界

目前云端链路只支持百炼；不引入订阅、账号、团队协作或复杂生产力仪表盘。本地保存与“不保留历史”的临时结果策略都由原生后端管理，前端不成为数据库或密钥的权威来源。

自定义 Mode、服务地域及麦克风在设置/Mode 面板配置。悬浮栏保持录音、Mode、取消和结束的核心操作；错误恢复按实际阶段呈现，不把云失败、保存失败和输入失败混成成功。
