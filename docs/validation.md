整理保留实际生产功能，开发路径改为项目专有目录，测试不依赖原机器 D 盘。以下结果应以本次实际执行后更新的表格为准。

| 范围 | 当前状态 |
| --- | --- |
| 前端 TypeScript / Vite | 2026-10-08：`npm ci` 与 `npm run build` 通过 |
| 四个前端 helper | 2026-10-08：27 项通过（字幕 8、波形 7、电平 6、输入反馈 6） |
| Windows desktop Rust 库 | 2026-10-08：289 passed、0 failed、1 ignored |
| 仓库文件、敏感数据和本地链接 | 154 个暂存文件检查通过；第三方资源 14 件保留原字节 |
| 当前克隆的 release / NSIS | 2026-10-08：构建退出 0，生成 `SpeakMode.exe` 和 `SpeakMode_0.1.4_x64-setup.exe` |

本次在整理副本执行上述命令，使用 Node.js 22.17.0、npm 10.9.2、Rust 1.99.0 和 x86_64 MSVC。Rust 全库命令见根 README；本机运行同时使用 `--offline`，并复用已准备的工具链与依赖缓存。289 项包含两项新增的开发资料路径测试。忽略项是由父测试启动的维护服务 child，不能把该项算作独立失败或独立直接执行通过。

前端构建存在 Radix `use client` 指令和超过 500 kB 的 bundle 警告，未阻止构建。此次源码整理未将性能优化或警告消除列为已完成结果。

实际打包命令为 `npm.cmd run desktop:build -- --ci -- --locked`。第一次使用 `npm` 的 PowerShell 包装器时参数分隔符被吞掉，CLI 以参数错误退出；改用 `npm.cmd` 后完整构建通过。构建保留两个未使用 engine 方法的 `dead_code` 警告。新产物只保存在本机，本次上传的是源码，没有发布 GitHub Release 或安装该包。

本次成功对应整理后的克隆；它不改写前文原始构建中断的历史记录。构建成功也不代表真实录音、所有宿主输入或安装升级卸载已经验收。

真实麦克风波形、长停顿与尾词、云端 ASR、最终语义、用户实际宿主输入、语音时延分布、配置升级、安装/升级/卸载和 HCI 用户任务需要各自的证据。合成 helper 不触碰用户音频或云账号；本轮源码整理不重新采集真实口述。
