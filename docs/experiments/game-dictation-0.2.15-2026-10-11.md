# 0.2.15：重复数量与局部类型描述的误回退修复

## 根因和增量

用户反馈的游戏口述仍保留大量停顿词。只读核对发现实际运行程序与 0.2.14 发布 SHA 一致；最新来源与用户主动提供的原文忽略空白、标点相等，回退原因为 `meaningRisk`，停止至成稿约 924 ms。数据库没有保留被拒绝响应，不能还原当次触发细节。

新执行两次 Qwen 3.8 Flash 文字整理请求，分别使用冻结生产提示与已有实验提示，均未重试。两份生成内容已完成主要口头语清理，却都被数量保护拒绝。原检查把相邻的“一个这样的一个对象”当成两个独立数量；另一阻塞是“是一个某类型”与“是一款同类型”的局部关系缺乏表达。模型请求总耗时分别 881 / 1193 ms（其中云调用 878 / 1190 ms）；不是本地采音、ASR 或真实粘贴耗时。

本版增加限定数量角色匹配：只在相邻重复限定、候选保留同一完整对象和数量时归并重复提及；分类词变化必须匹配完整类型与所属对象。候选“这”只能由紧邻且唯一的介绍建立联系，名称必须来自明确来源。没有游戏、工具等题材名词白名单。

新权限还要满足所在来源块的数量出现次数下界，防止同一候选数量反复佐证多个对象。候选新增分类也需要反向来源见证。源码、来源引用和正文从不被这层检查改写。

生产模型、提示、等待预算、一次性输入及完整识别稿回退保持原实现；没有新增云调用或自动打开面板的产品行为。自动模式在本次模型结果中仍选择自然段，未与此修复同时改动为强制列表。类型大写和列表排版属于后续呈现优化，不能与本次“不再误退回原稿”混为同一指标。

## 评审和验证口径

独立 Agent 对原稿和两份生成正文共 3 个去重文本做隐藏实验身份的检查。两份生成内容在保真、清理、可读性、语气、专名五维均通过，无关键语义错误；原稿清理和可读性未通过。这是文字评审，不是真人听评或 Typeless 同音频对照。

独立数量挑战在读取实现前冻结：12 个公开合成案例、两个解析器、24 个原文恒等控制，共 48 项。基线符合 36/48，包含 4 个正例误拒与 2 个反例漏拦，各在两个解析器上复现。固定语料和首次失败保留，不通过修改预期把结果改成通过。

实现审查额外覆盖同句主观判断不能变成客观断言、分片命名标签不能充当名称、重复数量豁免不能吞掉“另一个对象”，以及候选新增分类数量的逆向来源关系。
