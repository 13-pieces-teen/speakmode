# SpeakMode 0.2.2：UI体验精修验证

2026-10-09。比较基线为已合并0.2.1（`c30acdd`），本版桌面0.2.2／前端0.4.2。范围见[版本计划](../plans/ui-0.2.2.md)。本机证据目录为 `D:/Codex_Project/SpeakMode_Dev/evidence/ui-0.2.2-2026-10-09-r1`。

## 相比上一版的增量

- 首页长口述默认有限预览，可展开和收起。复制仍引用完整成稿版本，短口述不出现多余开关。今日用量保留顶部，字数加千位分隔，卡片与Mode视觉体系保持。
- 宽屏历史列表独立滚动，标题与搜索框保留；窄屏仍使用列表／详情切换。搜索过程中显示加载状态，不提前宣告没有结果，并隔离旧查询失败。
- 详情的换整理、纠词、删除与候选结果打开后定位到内容；取消回到对应按钮。旧取消ACK不会关闭随后打开的新面板。
- 常用设置的保存中／成功／失败显示在操作行附近。默认Mode采用紧凑选择器，个人Mode再多也不逐项撑高页面，说明、管理入口和示例保留。
- 词典取消编辑、取消删除、完成删除及清搜索都有明确焦点落点。720px窗口的五项导航统一为一行；更窄布局使用图标在上、文字在下。

## 基线与失败记录

使用生产React构建、16条合成历史、长口述和真实headless Edge点击采集。三种基线尺寸为1440×900、1024×768、720×640；另对新版430×720做补充布局回归。页面数据不来自个人历史。

基线1440×900中，首页复制操作顶部约1233.5px，初屏不可见；滚动长详情后，历史搜索框顶部约-872px。设置语言保存反馈在长页底部，三种尺寸均不可见。720px时五项导航实际排成4+1。

第一轮13项检查12通过、1失败：历史卡片高度仍超过初始主视口，浏览器为滚动列表先推动整页，带走详情位置。该失败保存在 `green-r1`，不因目录名含green而改写为通过。收紧桌面卡片高度预算后复测。

只读复核还发现取消生成的旧ACK会关闭用户随后重新打开的Mode面板。用首轮dist单项复现失败，保存于 `cancel-ack-red`；修复将收起与焦点处理放在本次用户动作内，旧ACK返回后不再操作新面板，保留原请求代际检查。
