# 0.2.12 词汇迁移与安静完成验证

日期：2026-10-11。基线 0.2.11 / 0.4.10，新版 0.2.12 / 0.4.11。

## 功能增量

词典页新增“导入 Typeless”按钮，点击后将本机词汇追加到 SpeakMode，重复词合并且保留已有词的拼写。保存使用既有词库版本检查和原子事务；来源错误、内容不完整、无效词条、容量不足及并发更改时不部分保存。词条用于下一次录音。

主面板移除正常完成后“输入已派发／查看成稿”的持久恢复卡片。实际未输入、部分输入或识别/存储失败仍保留必要复制与恢复操作。原生交付状态、历史、源稿及不自动重试的规则不变，也未新增自动打开主面板行为。

## Typeless 来源与边界

本机 Typeless 2.8.1 的 SQLite 只存历史，词典由 `/user/dictionary/list` 云端接口加载。本功能读取 `%APPDATA%/Typeless.exe/Partitions/no-proxy-session/Cache/Cache_Data` 中已存在的词典响应，不请求该接口，不读取登录凭据或历史数据库。

仅解析已验证的 Chromium blockfile 格式和 active index；不搜索删除后的残留词、不合并筛选页、不回退到较旧完整词表。只读共享打开文件，校验读取前后相关字节一致；格式、块地址、大小、编码与完整词条数量均有检查，Brotli 解压有硬上限。新增 EntryStore、RankingsNode 非零 self_hash 和完整缓存键 PersistentHash 校验，兼容 Chromium 的零 self_hash；稳定但损坏的正文指针不得借用旧响应。该非密码学哈希用于格式完整性检查，不是来源身份认证。未知格式或缓存更新时返回可读提示。使用锁文件中已有的 Brotli 9.0.0，不更新其他依赖版本。

这是本机缓存迁移，不是云端实时同步，也不保证兼容 Typeless 的未来版本。按钮提示和“词库说明”说明：如刚修改 Typeless 词典，先打开其“所有”页面更新，再导入。修改原 Typeless 词典不会自动覆盖 SpeakMode。
