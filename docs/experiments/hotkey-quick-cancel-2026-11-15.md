# 快速双按必须取消 · 0.2.46

规则：第一次有效触发开始录音，不超过 500ms 的第二次有效触发取消；超过 500ms 则正常结束。F8 等普通触发键使用物理按下时间，长按自动重复不构成第二次。单独修饰键继续保留独立手势和原生组合规则。

0.2.45 已保留原始事件时间并能选对 Cancel，但生产 FIFO 还在等待第一次 Start 的完整凭据/浮层回执。因此第二次即使 100ms 内入队，也可能等到采音/识别已启动后才真正取消，甚至被尚未结束的原生显示一直阻挡。

本轮将 Start 分成同步准入和后台启动。同步创建 Starting 会话、冻结配置并持有处理 lease 后，队列即可处理下一次输入；凭据读取和浮层回执由后台所有者完成。第二次取消能够立即撤销同一会话令牌，迟到启动必须再次检查身份、取消和退出状态，不得启动采音/云端。UI 手动启动仍等待完整结果；后台启动失败继续回报当前会话，正常取消及旧会话错误不重新弹出。

取消的浮层收起和完成边界独立于监听恢复结果，恢复失败不能跳过收尾；错误仍上报，资源未真实释放时也不允许新录音。取消完成前的旧排队触发继续忽略，正常释放后的新按下不增加全局冷却。

凭据/浮层尚未成功就失败的初始会话，在 500ms 内收到第二次触发也按取消处理；显式停止、已经有来源/成稿或恢复操作继续保持原门禁。后台启动的 panic 转为可见失败，不能遗留 Starting 忙状态。

显示及启动错误都在真正执行 UI 回调时复核当前状态：已取消、取消中的旧浮层不再显示；已取消或错误已变更的启动回执不再弹出旧错误。501ms 正常停止仍允许完成原收尾。
