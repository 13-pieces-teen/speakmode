# 0.2.6 词典精简验证

2026-10-09。本轮基于本机 0.2.5，桌面 0.2.6／前端 0.4.5。保留上一轮语义和诊断改动；本轮集中在词典 UI，不变更原生存储、模型或语音链路。

## 实际变化

| 原表现 | 新表现 |
| --- | --- |
| 双层标题、长列表、行内编辑和删除双按钮 | 单标题、带数量的搜索工具栏、3／2／1 列词卡；点击词卡编辑，更多菜单删除 |
| 顶层两个添加入口，编辑器把列表往下推 | 一个“新词”按钮，居中小弹窗；批量添加放在弹窗左下 |
| 字节容量条和多段说明常驻 | 词库说明、草稿容量折叠；接近／超过预算时给出提示 |
| 原有表单版本保护 | 保留草稿和版本冲突处理；冲突弹窗显示当前已保存值便于核对 |

仍支持搜索、新增、编辑、删除、批量按行粘贴、重复词处理和下次录音生效。没有自动学习来源分类或 CSV 文件导入。容量估值不禁用保存，避免把后端能合并的 Unicode 等价词误拦；真正的 200 条／80 字／4000 字节限制仍由原生端判断。

## 交互修复与证据

1. 保存单词后切换批量入口，排队动作读取最新快照版本；验证请求 expectedVersion 从 1 到 2，没有使用旧版本。
2. 删除遇到并发删除后，对话框关闭并把焦点移到相邻词条或列表标题。
3. 编辑冲突保留草稿，同时展示当前已保存词条；不会让用户对着不可见背景核对。
4. 取消脏草稿仍弹出保存／放弃确认，处理中不能重复提交或关闭。
5. Dialog.Title 使用 Radix 自动 ID，恢复对话框可访问名称。
6. 截图发现全局 .radix-themes 底色误作用于 portal，遮住整个背景。现底色只施加在根主题，保留原生半透明遮罩。终态检查 dialog opacity=1、白底，overlay 自身透明，页面背景可见。
