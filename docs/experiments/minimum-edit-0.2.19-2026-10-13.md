# 0.2.19：最小必要编辑的链路升级

本版把默认自动、轻整理、结构与自定义 Mode 的基础清理统一；布局由 Mode 和兼容的个人规则决定。补齐受限局部修复、取消/期限检查与修复失败的原稿交付，保留可编辑的历史候选。已选择的范围是百炼北京 `qwen3.8-flash`，不是整个模型列表的质量背书。

初始总预算 112 次；发现接口兼容、漏检及超时问题后，追加有界的独立诊断，最终总上限 118，保守计账 117。中断案例按最大 7 次计，不能作为精确服务账单。没有生产自动重试，也没有用补跑替换原始失败。

JSON 模式要求消息里明确包含 JSON 关键词，参见[百炼结构化输出文档](https://docs.modelstudio.console.alibabacloud.com/zh/model-studio/qwen-structured-output)。首个服务错误没有记录具体 HTTP 原因，因此不能证明只有这个前置条件导致了它。

## 本版工程行为

- `rewrite_minimum.rs` 同一基础清理，单块全文输出，原生绑定全部冻结来源。显式模式不可被重路由；源文、词典提示和个人规则作为数据，个人规则不能授权新增事实、删除条件或改变请求身份。长中文口述仍保护英文拼写、代码与引语，恢复后再检查。
- `rewrite_semantic_review.rs` 分开检查覆盖、事实、限定、意图与清理，绑定同一来源/草稿和 Mode。模型判断是证据而非证明；形状、数值、限定及引语检查继续独立执行。
- `rewrite_local_repair.rs` 仅对其他保真项通过且唯一可定位的局部问题操作，最多两处、每处最多 80 字；源/Mode/草稿哈希和原生 UTF-8 范围固定。模型只可返回已知 ID 的替换，不接受全文、索引、重复或额外 ID。
- 对很窄的多重卡顿句头，本地提示即使模型漏看也会阻止直接放行。只有模型修复精确等于允许的句头删除、其余所有字符和元数据不变时本地验收；否则新全文复核。无变化的修复拒绝，不循环处理。
- 自动流程最少两次请求，最多四次，纯句头删除路径三次。仍共享原 5/8/20 秒期限；取消优先、超时/无效修复返回完整识别稿、来源或任务失效不能转成可输入文本。输入只尝试一次，不自动打开主面板。
- 历史人工候选与 Mode 试用使用同一生成规则，每种布局一次调用，保真提示不会锁死候选。用户明确保存、版本冲突、来源映射、撤销及不重复输入契约保留。试用报告实际生成协议，不再固定标为旧版。
- 诊断只增加固定协议/错误代码，过滤模型正文、核对摘录与 Key；无数据库迁移，无个人配置改动。
