## 实际交付

- 固定录音浮条为 274×48 CSS px，原生基础窗口为 298×68；默认只显示取消、状态/声波和结束。只有采样就绪才显示“正在听”。处理阶段显示简短状态。
- 字幕新增持久化开关，默认关闭；开启后复用原有修订、尾部跟随和快照逻辑。使用引导中的字幕仍按教学需要显示。
- 场合选择保留托盘入口，复用原生菜单焦点协议；菜单不再占用日常浮条空间。
- `recorderPresentation.ts` 统一浮条与主窗口恢复提示的状态、文案和动作。正常未确认派发安静结束，不把系统派发回执写成目标应用“已填入”。
- `window.dismissRecorder` 只隐藏提示，保留当前会话及恢复缓存。它校验会话 ID/代次，并在原生 UI 线程再次校验；旧请求不能收起新一轮会话，准备/派发中不能收起。
- “查看结果”携带当前会话标识，原生将导航请求保留到主窗口确认。主窗口复用现有未保存编辑保护；过期确认不能清除新的导航请求。
- 结果页突出正文、复制和纠词。模式重整、手动编辑、恢复、删除与本次参考折叠到次要区域。纠词仍只修改精确选区，记入词典默认不勾选，保留事务与版本冲突处理。
- 整理回退、部分输入和回执保存失败会保留可恢复提示；“收起”与“放弃恢复”有不同语义。

本轮没有修改 ASR/整理模型、完整性检查、整理时间预算、目标捕获和一次性投递策略。已审阅并保留目标与可选参考分离、取消代次校验、完整原文回退、保存与派发记录约束。新增字幕配置采用旧配置缺字段时默认关闭的兼容读取方式。

没有真实前后速度数据，所以不宣称识别、整理或端到端输入变快。P3 的速度优化仍需使用相同素材、设备和服务记录真实基线后再决定。

## 界面检查

浏览器使用 `scripts/simplified-dictation-browser-fixture.py` 复制当前 `app/dist`，从 loopback 端口 4187 提供隔离夹具；交互由 CUA 操作。夹具的模拟控制按钮不属于产品。

交付核对时发现首轮夹具只复制了 assets，遗漏 public 字体。已修正为复制完整 dist，并重新检查默认浮条、字幕/菜单高度、模式选择、恢复提示和结果排版，重新生成交付截图。最终默认窗口仍为 298×68，字幕/菜单最高 419 px，部分输入恢复窗口为 344×155；字体请求返回 200。正式程序的字体资源完整，本次修正只涉及验证夹具。最终夹具所引用 JS/CSS 的内容哈希与最终生产构建一致。

| 场景 | 观察结果 |
| --- | --- |
| 默认录音 | 298×68 窗口内无裁切，字幕不挂载，声波不挤压状态文字 |
| 显示长字幕 | 窗口扩展到 344×116，最新文字尾部可见 |
| 托盘模式菜单 | 向上展开；字幕与菜单合计最大 419 px，未超 420 px 限制；选择后立即关闭，只有一次选择命令 |

浏览器工具记录到 `MutationObserver.observe` 的非 Node 异常，来源 URL 为空，堆栈尾部为 Electron sandbox。页面与 iframe 的自有 error 监听没有捕获到对应错误，独立主页面也没有该错误；因此将其记为浏览器宿主/注入层疑似异常，**不宣称所有浏览器控制台无错误**。夹具没有实现今日概览统计 IPC，该合成页面的统计读取失败不作为产品统计结论。

原生 UI：从同一实现源码的首份 0.2.33 构建启动，测试资料位于交付目录 `native-profile/`。完成新资料引导跳过、设置页访问、字幕关闭→开启→关闭、保存提示观察。只读核对测试 SQLite：`preferences.version=3`、`recorderCaptionsEnabled=false`、schema 6。退出走该测试 EXE 的正常资源释放流程，没有删除资料或凭据。最终交付包是随后通过预算检查的重建产物；本轮未执行其安装/升级流程。
