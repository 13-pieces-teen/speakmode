# 0.2.30 口述日期与断续缩写

用户在长句、中英混说中需要数字日期，并希望恢复断续读出的缩写，同时保留真正独立的字母。本版实现共享的 `spoken-format-v1` 策略，适用于正常整理、场合写作、兼容供应商旧模式、历史候选和局部修复。没有新增设置或数据库迁移。

## 行为

| 口述/识别文字 | 成稿格式 |
| --- | --- |
| 我们讨论 A D H D 的研究，日期是二零二六年十月二十三日。 | 我们讨论 ADHD 的研究，日期是2026年10月23日。 |
| The report date is 二零二六年十月二十三日. | The report date is 2026-10-23. |
| I will graduate in twenty twenty seven. | I will graduate in 2027. |
| The backup is June fourth. | The backup is June 4. 年份保持缺失。 |
| 同时评估四个模型 A、D、H、D 的效果。 | 字母标签保持分开。 |
| 四个独立字母 A B C D，每个写三遍。 | 字母保持分开。 |

上述是格式处理示例，不是云端模型质量测量。列表中的数字、条件和否定仍是有效内容，不因格式规范而删除。

完整英文日期用 ISO 数字形式；缺少年份的英文日期保留月份名称和数字日，避免用纯数字制造新的月日歧义。相对日期、星期和 `3/4` 不按当前时间解释。原始记录若是二月三十日，只改变数字写法，不用常识修正为别的日期。路径、标识符、引号/代码和明确逐字保留的日期跳过本地转换。

缩写只合并同一顺序的原字母，不扩写含义，不推断诊断或新专名。有限词表覆盖 ADHD、LLM、RAG、API、AI 等；其他词只有在明确称为缩写且无独立字母/不确定提示时才合并。`a I` 等文章词和代词不自动视作 AI。数字加复数对象的标签、选项、拼写教学、变量和不明确字母序列优先保留。

## 实现与保真

长中文路径此前会保护英文片段的原始写法，导致断续缩写原样恢复。本版在创建保护标记前规范派生文字；原始 SourceRevision、ASR 分片、来源 ID 和哈希不变。其他生成结果在进入复核前使用同一格式器。局部修复后先规范并重新准入，再取得绑定新稿的独立复核；不会在接受复核后偷偷改稿。

生成、语义复核、局部修复共享口述格式策略与有上限的缩写提示，不额外发请求。日期事实提取按同一日期的年/月/日分量比较，并保留原来源坐标与所属子句；等价写法可比较，改值不能因数字化被豁免。独立字母合并、字母替换和缩写改字即使收到五项全部通过的模型复核，也仍需通过本地检查。需要人工核对的历史候选保留风险提示。

实现还修复了三个开发中发现的反例：多个模型标签误合并；日期后的 `two thousand people` 被吞成年份；未完整识别的 `two thousand five hundred` 被截成2005。日期和标签上下文先截取固定窗口，连续数字解析有上限，已识别年份位置使用有序查找，避免无标点长输入中的重复前缀扫描。

## 验证范围

- 冻结合成格式语料24条，覆盖长段混说、跨分片缩写/年份、口头停顿、多个缩写、独立字母、拼写、选项、代码、地址、完整/缺失/歧义日期、日期变化历史和非日期数字。检查必含/禁含内容、原稿不变及本地准入。这些样例参与开发，不是独立预留集。
- 本地 HTTP 流程覆盖长中文保护、显式英文场合、兼容供应商旧模式、人工历史候选、确认后的历史候选、改字/改日期拒绝，以及修复后重新绑定复核。正常路径仍是两次请求，旧兼容路径一次，有局部修复时最多四次。
- 增加长无标点文本检查：一万位连续数字、重复模型标签和重复英文年份。不以固定毫秒阈值冒充用户端速度测量。
