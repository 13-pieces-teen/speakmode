# SpeakMode 0.2.24 使用引导接入与验证

本轮将已选定的动效原型接入 React/Tauri 正式应用。新用户按「欢迎 →
服务与麦克风 → 快捷键 → 聊天口述 → 文档口述 → 开始使用」完成两次练习。
结果来自当前原生会话，不再播放预置成稿。朗读脚本只是提示，允许自由表达。

## 已实现的行为

- 新数据库自动进入引导；v1/v2 数据库升级后保留原有工作入口，不强制重新学习。
- 暂停保留当前步骤，完成需要两次原生会话的结果凭据；两者分别记录。
  设置可重新打开，未完成用户在首页可以继续。
- 使用正式采音、实时识别、整理与来源保留链路。练习临时选择聊天或文档场合，
  冻结为预览交付，关闭本次附近文字采集；不会改写全局交付和场合偏好。
- 引导内显示音量、字幕、实际成稿和识别原文；提供取消、可用的识别/整理/保存重试，
  以及复制失败后的手动复制。原文回退明确标注，不冒充整理成功。
- 快捷键测试复用原生热键入口，只返回按键信号。主窗口失焦时不允许新建一条
  日常直接输入会话；隐藏或最小化进行中的练习时，请求显示原有录音浮层。
- 服务配置默认显示账号地域与 Key，高级模型和业务空间可展开。未保存内容阻止离开。
  Key 仍由既有系统凭据保管库接口管理，保存配置不等于连接验证。
- 保留雾蓝背景和固定舞台，提供系统及手动减少动态效果、键盘切换即时响应与标题焦点。
  首次激活引导期间显示连接状态，避免先闪现正常首页。

练习文字和统计遵循已有设置：计入口述统计；关闭历史时使用原有内存保留策略。
新增 SQLite v3 表只存步骤、已练习场合与完成时间，不保存正文或凭据。
v3 数据库不支持交给旧版 v2 应用直接读取。

## 复查方式

原生检查继续使用项目的 Windows 构建入口，准备本机 MSVC 环境后运行
`scripts/build-desktop.ps1 -Task Test` 和 `-Task Package`，保持同一个有界编译缓存。

浏览器夹具保存在 `scripts/onboarding-browser-fixture.html`。将它复制到
`app/.validation/onboarding-fixture.html`，在 app 中启动 Vite，再访问
`/.validation/onboarding-fixture.html`。该目录被忽略，不进入正式包。
夹具只使用假设备、假凭据和合成结果；不要输入真实 Key。
`?slowOpen=1` 可验证引导激活延迟；页脚 QA 控件可以切换失败、回退和已有用户状态。

真正的验收应在桌面安装包中执行：新配置保存 → 实按快捷键 → 两次本人录音 →
核对输出 → 退出引导 → 在自己的常用应用中完成输入，并检查无法输入时的复制路径。
这里的实现与自动检查尚不能证明新用户学习时间或改稿量已经下降。
