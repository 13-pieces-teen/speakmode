# 0.2.8 轻语增强：实际验证

日期：2026-10-10。桌面 0.2.8／前端 0.4.7。本轮为实现与离线工程验证，**真人轻声识别质量、真实设备、宿主输入、安装升级未验收**；没有麦克风或云端调用。基于本地 0.2.7 工作树的增量，尚未推送。

## 功能与范围

设置的「录音与输入」分组新增轻语增强，默认关闭，保存后下一次口述生效。独立于输出 Mode；旧设置兼容、重启持久化、恢复默认均有测试。采音工作线程在 16 kHz 浮点数据量化前执行受限增益与峰值保护，无新增音频等待缓冲，不裁掉低能量或停顿。缓存增强后的 PCM，重试原样重放。

参数和限制见 [本版实施说明](../plans/soft-voice-0.2.8.md)。所谓增强在本版指数字电平处理，不能表述为已有真实 SNR 或转写准确率提升。

## 合成信号实际电平变化

同一信号分别进入旁路、固定 +6 dB 和轻语自适应。以下为轻语臂相对于旁路，未经过 ASR：

| 信号 | 整段 RMS 改变量 | 输出削波样本 |
| --- | ---: | ---: |
| 低音量谐波包络 | +11.4603 dB | 0 |
| 普通音量语音替代信号 | +2.9171 dB | 0 |
| 数字静音 | 0 dB，仍为全零 | 0 |
| 稳定低电平宽带噪声 | 0 dB | 0 |
| 轻声信号突然转大声 | -0.6201 dB，峰值约 -1 dBFS | 0 |
| 1701 样本短尾 | +8.6911 dB | 0 |

所有臂样本数不变、数值有限，旁路位级一致。普通音量也发生电平变化，不能声称开启后对正常声音完全无影响。突变样本的整段 RMS 下降来自峰值保护；不应解读为真实口述质量退步或提升。

探针为 **debug 单次运行**，轻语臂每个 100 ms 数据块记录到的最大处理耗时为 54 μs；只含 DSP，不含采音、重采样、网络、模型、UI或输入。这个数不能称为生产 P95、用户感知时延，或相对旧版的端到端速度提升。

可复现入口：在已配置的统一 MSVC/缓存环境运行 `cargo run --locked --manifest-path app/src-tauri/Cargo.toml --target x86_64-pc-windows-msvc --features desktop --example soft_voice_probe`。其 main 不调用设备、云端、用户数据库或系统输入，仅输出合成数值。
