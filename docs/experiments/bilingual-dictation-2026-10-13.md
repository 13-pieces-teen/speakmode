# 英文主导口述：复现、候选淘汰与事实检查

## 结论

本轮尚未解决真实自我介绍的自动成稿问题。两版语言规则都能清理不少卡顿，但用户样例仍被事实复核拒绝、整段回退；第二版还在独立合成样例中遗漏跨片段年份的尾数，复核却放行。不能把更流畅的草稿或模型 accept 当成质量通过。

英文生成/复核候选仅保留在 `experimental-english-dictation` 编译特性，默认关闭。普通桌面构建继续使用 v3 提示词；本轮不发布安装包、不更改用户运行中的 0.2.21，不修改历史、词库或采音配置。生产可用的代码改动是英文明确数值/单位的检查及有限的跨片段年份保留检查。

## 证据与实验过程

基线是 `b2800d8` / 0.2.21。只读匹配到用户所给口述：124410ms、11个 ASR SourceItem，来源完整，输出为 meaningRisk 原稿回退。原会话没有持久化模型草稿，不能断言当时是哪一个词触发拒绝。

使用原11个片段顺序重放；不编辑用户来源，不把它预先重切成通顺句子。实验读取正常北京 qwen3.8-flash 配置，固定文本调用，无新增 ASR/真人录音/目标输入。样例重建实验会话身份，并不冒充原会话的 SourceRevision。当前实验接口使用空词典快照，不能冒充带用户词典的 ASR 回放。

|---|---:|---|---:|
| 原 v3 用户样例重放 | 2 | facts=fail，完整原稿回退 | 4138ms |
| v1：通用提示后追加英文规则；用户样例 | 2 | facts=fail，回退 | 10069ms |
| v1：合成经历/金额/跨片段年份 | 2 | facts=fail，回退 | 3222ms |

本轮共16/16次文本请求，与之前场景实验单独记账；失败和诊断请求也计入，停止新增请求。默认生产 reviewer 的512-token上限没有扩大；2048只用于明确调用的离线诊断，诊断结果不能授权交付。

最后诊断把主要疑虑定位到跨ASR边界的年份：它不能确定下一片段开头的数词属于年份还是噪声，因而拒绝等值接续。用户已确认实际年份，故可将该点记为相对于用户参照的误拒；但这是后续冻结草稿的解释，不是原会话当时拒绝原因的完整回溯。诊断说明本身过长，严格协议仍拒绝，没有因获得解释而授予交付权限。

用户确认专名、研究主题及比赛信息，并选择英文成稿。确认信息只作为本地质量参照，没有加入词库或硬编码进提示词。完整用户原文、候选与供用户核对的目标稿均留在仓库外。本仓库仅保存合成素材和一个真实模型错误的合成样例收据。

v1预留样例在结果被用于修改v2后已是开发样例。v2预留样例在首次调用前冻结；发现错误并加入确定性回归后，它也成为已曝光回归案例，不能再次称为独立验证。

## 确定性检查

- 修复数字前的空格被吞掉的问题：`budget is 30 dollars` 过去把前面的 `s` 当成数值所属标识符；现在只把紧邻的字母当作标识符的一部分，仍保留 Qwen3.8 等名称边界。
- 有限英文整数与明确单位规范：`twenty seven hundred dollars` 与 `2700 USD` 等值，`sixty seconds` 与 `1 minute` 等值；金额、时长或单位变更拦截。支持百/千及部分常见单位，不解析无限英语数量表达；不将不支持的小数/百万表达尾部当成独立数量。
- 对 `in/year` 后可识别的1900–2099年份，读取完整来源中的ASR边界，保留明确的年份尾数。只在数字尾词明确结束时跨 `句点+换行` 接续；`Two teams joined` 仍是下一句。明确改口形式不在这个年份解析器内，交给原有语义复核。
- 新年份检查仅检查来源已明确识别的年份值是否仍在，不证明数值归属、次数或没有凭空增加日期；未知日期格式仍需语义复核。来源、Mode、引语代码、共同期限、取消和完整原稿保底继续独立执行。
- 将v2曾被模型放行的完整合成响应作为固定回归：本地检查应在再次请求reviewer之前拒绝它。该验证是旧响应的离线重放，不是新增云端成功率或性能测量。

## 下一阶段

1. 将“已确认术语”与普通词库分开建模：来源身份、精确错词片段、目标词和确认记录需可追溯；仅存在一个词库词条不能授权模糊替换。
2. 为低置信局部提供保留/纠正后的候选审阅，保留其余已清理句子；自动交付仍要求最终复核，不能将待核对草稿直接粘贴。
3. 使用带原始音频的中英切换、自我修正和年份断片测试，分别测 ASR 词错率、成稿可用率、误改率与回退率。固定文本结果不能代表真人录音质量。

## 工程验证

普通桌面配置与开启实验特性的release配置分别完整测试788 passed / 0 failed / 3 ignored，包含冻结错误响应在模型复核前被拦截的回归。Python诊断导出37项通过。初轮新增数值测试曾失败，修复后通过，失败日志保留。实验工具编译成功，单一MSVC缓存11.931GiB，仍在12GiB限制内。没有本轮安装包、真人听写或宿主输入验收。

离线回归包含 `recorded_english_year_error_is_blocked_before_an_accepting_model_review`，读取仓库内冻结的合成输入和原始错误正文。实验特性只用于显式实验构建，例如：

```powershell
cargo test --locked --manifest-path app/src-tauri/Cargo.toml --target x86_64-pc-windows-msvc --features desktop --lib
cargo test --locked --release --manifest-path app/src-tauri/Cargo.toml --target x86_64-pc-windows-msvc --features desktop,experimental-english-dictation --lib
```

须先准备MSVC环境并通过项目缓存容量预检。`minimum_edit_lab --current-plan`不调用模型；`--current-run`最多按每条4次预留请求；`--explain-review`仅一次诊断请求，私有响应只能存放在仓库外。新网络实验须另立预算，不能续用已耗尽的16次记录。正式包不启用实验特性，也不使用`--all-features`。
