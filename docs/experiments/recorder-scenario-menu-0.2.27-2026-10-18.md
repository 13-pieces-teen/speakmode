# 0.2.27：更清楚的录音场合菜单

日期：2026-10-18；桌面 0.2.27，前端 0.4.26。

这轮改善的是小菜单中的选择体验。沿用 SpeakMode 白底、蓝色波形和蓝色结束按钮；选框宽 112px、菜单宽 184px、工具条 312×46px 均保持不变。

## 实现

- 自动推荐与手动场合用细分隔线区分，个人场合有独立分组。标题标明“仅本次”，避免与默认场合混淆。
- 名称由 11px 调整为 12px，单行高度由 30px 调整为 34px。图标使用浅色底，当前项有浅蓝背景和蓝色勾选。
- 鼠标指向或键盘聚焦时，底部显示该场合的用途；个人场合显示完整名称。说明区固定为 42px，最多两行，不因预览文字改变窗口尺寸。长名称在列表中省略，完整名称保留在可访问名称与提示中。
- 使用单选菜单语义。方向键可展开；菜单中方向键、Home、End 移动焦点并预览，点击或确认才提交选择。Escape 和 Tab 收起菜单。
- 鼠标展开沿用 150ms 的轻微位移与缩放，键盘及减少动态效果时即时显示。选项反馈即时更新，提交后立即收起，最终场合仍以原生回执为准。
- 沿用原有动态窗口上限 420px；长列表仅滚动选项区域。关闭菜单恢复字幕阅读状态。

## 验证

正式 React 组件通过浏览器夹具接收合成 IPC，iframe 随原生尺寸请求调整。12/12 检查通过，覆盖：

1. 112px/184px 尺寸、34px 行高、12px 名称与原有蓝色值。
2. 单一选中状态、仅本次提示、用途说明。
3. 鼠标预览不提交选择，也不改变菜单高度。
4. 键盘预览不提交选择，转为即时响应。
5. 方向键展开且不播放入场动效。
6. 350ms 合成模式应答延迟下约 7.8ms 收起菜单，仅提交一次。
7. 长字幕、错误、剩余时长与 23 项场合在 420px 窗口内共存。
8. End 只滚动选项区，个人场合名称出现在预览中。
9. Escape 恢复选框焦点与字幕阅读状态。
10. 减少动态效果时布局完整、过渡为零。
11. Tab 收起且不误提交场合。
12. 长个人场合名省略，完整名称可访问、可预览，说明区高度固定。

类型检查、前端生产构建、Windows MSVC / NSIS 安装包构建均通过（构建退出码 0，预算检查无违规）。构建结果见本机 `package.log`。

这是浏览器组件与合成原生边界验证，不能证明真实透明窗口合成、Windows 焦点、麦克风、云端质量或跨应用输入。本轮不更改 Rust 录音逻辑，未重跑完整 Rust 测试。
