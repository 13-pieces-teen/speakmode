# 从确认识别内容到可核对的自然成稿

## 本轮结果

新历史候选支持“本次确认”：划选精确原文、填写正确内容、选择英文成稿，先生成完整候选再复核。纠正后的参考同时进入生成和复核；原始识别稿不变。确认记录随采用的版本保存、复用和撤销，临时记录仍只存内存。复核有疑点时保留候选供逐处选择/编辑，避免历史候选因为一个疑点失去其余已整理内容。

这次恢复了真实用户样例中已确认的专名、研究主题及跨片段年份，英文卡顿、缩写和残句也明显减少。但模型仍把原口述的一个现在时改为过去时，五项复核漏检。结果不能算整篇无人核对即可采用；为此新增有限的时态变化提示，并保留实际失败证据。自动听写仍使用此前生产协议，本轮没有打开 `experimental-english-dictation`、发布安装包或改变运行中的应用。

## 原始请求与独立样例

基线为 PR #13 合并后的 `2ca51f5`，正常百炼北京 / qwen3.8-flash 配置。原用户案例沿用上轮只读提取的 11 个 ASR 片段和顺序；确认来自用户明确答复，仅用于本次本地实验，没有写入真实历史或词典。无 ASR、麦克风和宿主输入。私有来源、候选、确认范围、模型复核和调用账本都在仓库外，Git 只含合成素材和汇总。

新预留样例在首次请求前冻结，SHA256 为 `3f7feebd125ddf84b1ea88c6254f20ae99fd45e4d71049e506c23e4a2ef45800`。其中一条覆盖生僻机构译名、跨片段 2034、金额对比、未发布状态、批准条件和逐字引语；另一条覆盖重复同音词只纠正一处、未知名称备选、作者顺序、金额、代码和条件外的独立行动。这两条生成后没有用于调提示词。

总计 **11/12** 次真实文本请求，已停止。剩余 1 次不足以执行原计划的两次请求语言选项消融，因此该消融 `NOT_RUN`。一次基线调用因缺少预算字段在本地预检失败，发生于创建输出、读凭据和发请求之前，核实计 0 次，失败日志保留后补齐预算重试；没有隐藏网络失败或自动重试。

两条新样例对预先列明的内容检查均通过，但这是“原识别稿”与“增加用户确认后的参考”两种工作流的比较，不是相同信息条件下提示词胜率。新路径固定 20 秒预算，正常听写按长度使用 5/8/20 秒。少量非盲人工检查、模型 pass 和候选返回都不能推导日常准确率、自动输入成功率或优于竞品。

## 机制与证据边界

- 来源确认绑定原 source revision、Unicode scalar 范围、精确原文和正确表达。最多 8 处、每处 240 字，可跨片段。原稿字符不变，参考只替换选定范围；没有全局模糊替换或向词库学习别名。
- 生成/复核使用独立临时参考身份与哈希。其内部引用只用于检查，最终候选重新绑定全部真实 SourceItem；采用前仍核对会话、来源、当前版本和候选身份。
- 普通历史候选继续原单次路径。有本次确认或英文选项时最多两次请求：一次生成、一次完整五项复核，共用 20 秒期限与取消。前置检查使用已有生产五项链路的有限本地检查，避免额外套用旧 standalone 检查误拦等值英文年份。数值/单位、引语代码、已确认文字和来源绑定仍检查。
- 确认词的精确出现次数检查能发现遗漏，不证明实体归属；最终复核及用户对照仍必要。复核拒绝/协议无效时显示具体类别并保留候选；传输认证失败、限流、取消或超时不会成为成功候选。没有自动粘贴或后台采用。
- 本轮真实响应的时态错误在模型复核通过后才由人工发现。随后增加 16 组常见英语现在/过去动词的有限提示：在相同人称、动词和后续词框架内，某种时态减少且另一种增加时提示核对；排除引语代码，不修改文本、不宣称完整英语语法分析。它能覆盖本次已知误改，不能覆盖所有同义改写、第三人称或时态/状态错误。
- 时态提示和完整 Unicode 隐藏字符验证是在上述云响应之后加的。本地保留网络构建哈希，最终代码只离线复放已保存的时态错误；不把旧响应冒充又一次云端通过。复核五项通过也不能消除本地发现的提示。

采用版本可保留与原稿对照，可撤销确认记录。保存前的确认只是本次候选输入；现有“纠正词条”仍是直接修改当前输出的独立功能，不会凭一段输出自动猜测它对应哪个原始识别范围。历史确认没有自动输入权限，手工编辑后的文本也没有新的模型保真证明。

## 工程验证与下一步

普通 Windows desktop 配置：**800 passed / 0 failed / 3 ignored**。新增覆盖精确跨片段替换、Unicode 偏移、重复词只改一处、越界/重叠/旧来源/隐藏字符、确认随版本保留与撤销、memory-only 不落 SQLite、取消/期限、语义拒绝仍保留草稿、模型 accept 不能盖过时态提示。TypeScript/Vite 通过；新确认界面 5/5、原候选对照 17/17，均为生产 React 加合成 IPC，页面错误和外部请求为 0。最终时态提示文案另经这 5 项界面检查。
