# 短按唤起与浮层启动修复 · 2026-11-15

用户反馈 F8 短按偶尔不响应、长按更容易唤起，空闲首次按和刚结束/取消上一条后都可能发生。排查时本机运行版本为 0.2.44。本轮修复基于该版本；按后续远程合并与安装指令，将桌面版本更新为 0.2.45。源码回归与实际打包安装分开记录，安装结果以本机交付回执为准。

## 普通触发键立即响应

F8、F9、Ctrl+K 等包含普通触发键的快捷键，在修饰键匹配、没有额外普通键按住时，以第一次物理 key-down 产生一次操作，不再等 key-up，也不受原先 1 秒 tap 上限限制。同一次按住的自动重复、释放本身都不产生额外操作；真实释放后才允许下一次按下。按下后再补按别的键不能撤销已经发生的操作。

录音中的第二次有效触发仍按首次意图时间判定：不超过 500ms 取消，超过 500ms 正常结束。FIFO、生命周期 epoch 和旧排队输入保护保留。取消时的 hook refresh、配置更换、快捷键捕获或启停均保留仍按住的键闩锁，避免正在长按的 F8 在刷新后被当成新按下。停用/捕获期间仍跟踪真实 down/up，但不触发录音。

单独 Alt、Win、Shift 等没有普通触发键的快捷键继续等待独立手势释放，保留原生组合键和菜单屏蔽规则；其原有 1 秒上限保持。补偿事件也取消对应的修饰键手势，避免应用触发与原生菜单屏蔽不一致。

## 补偿释放与恢复

普通键/鼠标补偿在原生消息排空后运行。一次 up 采样只建立候选；持续 up 至少 30ms 后才发出一次 Reconciled。真实 down/repeat/up 或 down 采样会撤销对应候选。主鼠标任一按钮真实边沿同时清除两个旧候选，保持交换左右键及物理状态 OR 约束。

应用对 Reconciled 按键局部处理，不再清空其他普通触发键的 held 状态。若补偿的是触发键本身，则保持闩锁直到真实 key-up，避免无法区分来源的后续 down（可能是自动重复）再次操作。**真正漏掉触发键 up 时，下一次按下/释放可能只负责恢复准入，需要再按一次才触发。** 这是防止一次物理长按被拆成多次录音操作的保守边界；30ms 确认降低瞬时误采样机会，但不能保证系统权限/桌面异常时的持续零状态消失。

原生按虚拟键保留补偿前的 Key 映射直到真实 up，补偿后重复 down 不重新武装、不重复补偿；键盘布局变化或当前映射为 None 时，仍能配对原 Key，避免应用闩锁永久残留。

## 浮层与启动所有权

启动流程持有独立处理 lease，并等待浮层显示成功后才移交采音/云处理。显示失败明确进入失败状态、释放启动资源，下一次录音可重新准入。原生显示等待移到 blocking 线程，FIFO 仍等待实际完成以保持操作顺序；调用方取消等待不等于原生显示操作已退出。

普通 UI 队列超时规则保持。专用浮层显示若尚未开始可取消；若已开始，就等待真实完成回执，避免 3 秒超时后迟到显示却提前释放启动所有权。显示期间若取消、锁屏或请求退出，成功回执后仍要复核准入，收起迟到浮层且不启动采音。退出入口立即撤销启动准入，不再等清理阶段才关闭。

## 验证范围

新增回归覆盖即时 down、超过 1 秒的普通键长按、自动重复、补偿隔离、无关键补偿、cancel-refresh 重复边界、配置/启停/捕获、修饰键菜单一致性；原生连续采样、鼠标交换、原始布局和 unmapped up；浮层失败、慢回执、调用方放弃、取消及清理前退出。

最终 Windows MSVC desktop 库回归 **1167 passed / 0 failed / 4 ignored**，其中新增 12 个测试函数；vendored 键盘库 **107 passed / 0 failed**，其中新增 8 个测试函数。非测试 desktop `Check` 通过，仅保留原有历史协议辅助函数未使用警告。独立只读审阅未发现阻断问题。生产源最后移除一个不可达的兜底 match arm，运行行为不变，随后再次通过 Check。

测试使用合成键事件、可控原生回执和隔离 SQLite，未操作真实热键、麦克风、云服务或用户应用 UI。现场误采样仍未实机证实；代码修复与合成回归不等于物理键盘验收。没有改动前端实现，因此未重复前端构建。

本机日志在工作区 `output/validation/f8-short-press-fix-20261115/`：`desktop-tests-final.log`、`vendor-tests.log`、`desktop-check-final.log`。第一次全量测试 1166 项通过，但测试后的缓存预算检查超出默认 12 GiB。已只读审查旧测试产物；清理命令被自动审批审查以 `blocked by policy` 拦截，未执行删除。本轮保留全部缓存，显式临时使用 `-MaxCacheGiB 12.5` 完成后续验证，默认预算未改。最终缓存 12.179 GiB，D 盘可用 34.854 GiB；后续默认构建仍需要处置旧缓存或明确选择预算，不能把临时阈值理解为已清理增长。
