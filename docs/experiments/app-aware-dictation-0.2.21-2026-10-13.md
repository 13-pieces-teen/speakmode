# 0.2.21：应用偏好与停止时场景接入

承接[首轮场景成稿实验](scene-writing-2026-10-13.md)，本版把“稳定语义整理＋本地场景呈现”接入日常听写、预览、历史保存和现有一次性交付。桌面版本 0.2.21，前端 0.4.20；基线 `26dce0c`。

## 使用方式和实际变化

设置 → 整理与输出 → **按应用调整表达**，默认开启。常见聊天程序使用聊天呈现；Word/WPS/OneNote、代码编辑器分别选择文档和技术场景。用户可添加、修改或移除应用偏好，关闭开关会保留已有条目。

浏览器默认保持通用。给 Edge 或 Chrome 指定偏好会作用于该浏览器的所有页面；本轮没有网页任务识别。同一应用内需要不同输出时，显式选择轻整理/结构或个人 Mode 仍优先。

例如现有 Auto 返回：

```text
1. 如果会议未确认，不要订机票。
2. 先保留行程。
```

在聊天场景中保存并交付为：

```text
如果会议未确认，不要订机票。
先保留行程。
```

句子、顺序、条件、否定和来源引用保持一致。文档、技术、通用场景以及显式结构 Mode 保留现有呈现。本地转换范围沿用实验 v1：Auto、无个人规则、短且完整的平级列表。引语、代码、明确清单要求及不支持的布局保留成稿。集成复核额外覆盖“分点/分条/项目符号”和 bullets、numbered list、step-by-step；英文按完整单词匹配，listening 等词不会误中。冻结的实验候选文件未改动。

这次接通了用户控制和真实会话流程。自然接句、复杂改口、长篇组织的生成质量仍需后续实验，不能把应用名匹配等同于理解光标附近的写作内容。

## 会话与目标一致性

偏好在录音开始时冻结。停止口述后，复用现有目标快照中的进程和创建时间，只读取该进程的程序名；查不到或身份变化即使用通用处理。不采集应用正文、窗口标题或网页内容，完整路径也不进入设置、IPC、诊断或模型请求。

场景在生成开始前冻结，并绑定来源、Mode、会话代次和停止时目标。采集迟到不改变已经开始的整理。完成后复验绑定，仅在现有整理链路通过后应用呈现，再保存正式成稿。取消、超时/拒绝的原稿回退、显式重试及历史重写不借用这次场景改写结果。

预览模式也能采用停止时场景，但没有自动输入许可。直接输入仍走原生目标复验和唯一提交记录；本地格式转换不能授权第二次输入。录音浮层在整理阶段显示“聊天整理 / 文档整理 / 技术整理”，表示本次选用的场景。
